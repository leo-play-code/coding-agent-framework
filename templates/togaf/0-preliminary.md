# 準備階段 (Preliminary Phase)

> ADM 準備階段｜目的:確立組織的架構原則,並為企業客製化最適合的 TOGAF 框架與治理模型。

## 目的 (Objectives)
- 確認企業推動企業架構(EA)的承諾與範圍。
- 建立架構團隊、組織與治理結構。
- 客製 TOGAF 與其他框架,使其符合本企業。
- 定義並核可一套架構原則。
- 建立初始的架構儲存庫(Architecture Repository)與工具。

## 輸入 (Inputs)
- 商業策略、董事會/管理層的授權 (board mandate)。
- 既有的組織、流程、治理與既有框架。
- 既有架構資產與標準。

## 主要活動 (Steps)
1. 界定受架構影響的企業範圍。
2. 確認治理與支援框架。
3. 建立架構團隊與組織。
4. 客製 TOGAF 與選用的其他框架。
5. 制定架構原則。
6. 建立並導入架構工具與儲存庫。

## 產出物 (Deliverables)
- 企業架構組織模型 (Organizational Model for EA)。
- 客製化的架構框架 (Tailored Architecture Framework)。
- 架構原則 (Architecture Principles)。
- 初始架構儲存庫 (Architecture Repository)。
- 治理框架 (Architecture Governance Framework)。
- (視需要)架構工作請求 (Request for Architecture Work)。
