# 重構材料要準備什麼

> 這是**參考**,不是規定格式。你的資料夾怎麼放都行,我會自己掃描辨識;
> 只要告訴我東西放在哪就好。這份文件是給你「下次準備時知道要湊哪些東西」用的。

## 一支要重寫的舊程式,要湊五樣

| 要什麼 | 沒有的話 |
|---|---|
| **原始碼** — 舊程式檔本體 | 只能憑描述重寫,行為會走樣 |
| **查詢條件** — 每個查詢入口的參數、必填與否 | 條件對不上,結果一定不同 |
| **顯示欄位** — 欄位名、**順序**、小計/分組/總計列規則 | 逐格比對會在總計列失敗 |
| **輸出樣本** — 匯出 Excel / 列印的實際樣子 | 輸出格式沒得驗 |
| **對照結果檔** — 舊系統實際跑出來的匯出檔 | 只能證新系統自己跟自己一致,無法證明跟舊系統一樣 |

前三樣通常能從原始碼裡讀出來,你不必另外整理。

## 最重要的一件事:匯出檔要記得它是怎麼跑出來的

放了舊系統的匯出檔,**要能說出它是用什麼查詢條件跑的**(基準日、期別、廠商、科目…)。

不知道條件的匯出檔等於沒有 —— 我沒辦法用相同條件跑新系統來比對。
不用寫成文件,我會在對話裡問你,你直接講就行;但你自己要記得,或在檔名裡帶上關鍵條件
(例如 `應付帳齡_20260630_Q363.xlsx`)最保險。

一支程式如果有多個匯出檔(不同查詢條件),每個都要能說出自己的條件。

## 格式建議

- **CSV / Excel 最好** —— 可以逐格解析比對。
- **PDF / 截圖** 只能人工目視,證據力較弱,我會在報告裡標明。
- **未加總的明細列最有價值**;彙總報表也可以,但只能比合計數。
